# ファイル形式

## 対応

標準JSON、UTF-8、最大8MB。Prompt Workbench同梱形式と `prompt-workbench/tag-catalog` version 1形式を自動判定する。

## ラウンドトリップ

読込時に次を記録する。

- UTF-8 BOMの有無
- LF／CRLF
- インデント幅
- 末尾改行
- 元ルート、カテゴリ、タグの未知プロパティ

書き出しは元形式と上記スタイルを維持する。既存プロパティの挿入順はオブジェクト展開と既知キー更新で維持する。カテゴリ順、タグ順、既知のメタデータも維持する。

## 維持できないもの

- JSONコメント
- 同一オブジェクト内の重複プロパティ名
- UTF-8以外の文字コード
- 原本の絶対パスやファイルシステム属性

これらを検出・維持する必要がある場合は、標準JSONではなく位置情報付きパーサーを追加する必要がある。

## ComfyUI互換性

ユーザー形式は既存 `libraryToStoredCatalog` と同じ既知キーを出力する。同梱形式は既存の3階層配列を再構築する。エクスポート前にカテゴリID、親参照、タグ文字列、タグ所属小分類、重複を検証する。
