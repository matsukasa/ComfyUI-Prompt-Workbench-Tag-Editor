# データ安全性

- Chrome・Edgeなどの対応ブラウザでは、ユーザーがOSのファイル選択画面で開いたファイルのハンドルを同じセッション中だけ保持する。
- 自動保存は行わない。上書きは書き込み可能なファイルハンドルがあり、ユーザーが確認した場合だけ実行する。
- 別名保存はOSの保存場所選択画面を優先し、非対応ブラウザでは日時付きファイルのBlobダウンロードへ切り替える。
- タグデータはブラウザメモリ内だけで処理し、外部サーバーへ送信しない。
- 広告、解析、テレメトリー、リモートフォントを含めない。
- タグはReactのテキストノードとして描画し、`dangerouslySetInnerHTML` を使わない。
- JSON内のスクリプトを実行しない。
- 未知フィールドを保持し、認識できない形式は読込段階で拒否する。
- 重大な検証エラーがある場合は書き出しを禁止する。
- ファイルハンドルがない場合は上書きを無効にし、別名保存だけを許可する。
- 別名保存の候補名は `_YYYYMMDD_HHmmss.json` を付ける。
- 別ファイル読込、再読込、終了時は未保存警告を表示する。
