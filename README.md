# ComfyUI Prompt Workbench Tag Editor

`ComfyUI-Prompt-Workbench` のタグ設定JSONを視覚的に整理するローカルWebアプリです。タグの複数選択、カテゴリをまたぐドラッグ移動、3階層カテゴリの並べ替え、名称の直接編集、Undo／Redo、検索、重複検出、検証、差分確認、上書き・別名保存に対応します。

このエディターはComfyUI本体とは独立して動作するため、ComfyUIを起動していなくても利用できます。下記の手順でこのエディターのローカルサーバーだけを起動してください。

## 必要環境

- Windows 10／11
- Node.js 20以上
- npm 10以上
- Chromium、Chrome、Edgeなどの現行ブラウザ

タグデータを外部へ送信するバックエンド、解析、広告、テレメトリーはありません。起動後はオフラインで利用できます。

## 起動

エクスプローラーから `start-dev.bat` をダブルクリックしてください。初回だけ依存関係を導入し、以後は開発サーバーを起動します。

PowerShellから起動する場合：

```powershell
Set-Location 'D:\自作ComfyUIカスタムノード\ComfyUI-Prompt-Workbench-Tag-Editor'
.\start-dev.bat
```

手動セットアップ：

```powershell
npm install --prefer-offline --no-audit --no-fund
npm run dev
```

表示された `http://localhost:5173` をブラウザで開きます。

`http://192.168.x.x:5173` のようなLAN側URLはブラウザの安全な接続として扱われず、ファイルの上書きAPIを利用できません。上書き保存する場合は、起動したPC上のChrome、Edge、Vivaldiなどで `http://localhost:5173` を使用してください。

## 使い方

1. ヘッダーの「タグ設定ファイルを開く」でJSONを選びます。
2. 左ツリーで中分類を選び、中央の小分類カンバンを表示します。5件目以降は横スクロールまたは上部の左右ボタンで移動できます。
3. タグをドラッグして同じ小分類内で並べ替えるか、別の小分類へ移動します。
4. 離れた大・中分類へ移す場合は左ツリーへドラッグします。大・中分類は自動展開されるため、最後に移動先の小分類へドロップします。
5. ヘッダーの「上書き保存」または「別名で保存」で検証結果と変更数を確認して保存します。

### 複数選択

- Ctrl＋クリック：個別に追加／解除
- Shift＋クリック：直前の基準位置から範囲選択
- 各列の「表示中を全選択」：検索・フィルター後に見えているタグだけを選択
- 選択タグの1件をドラッグ：選択中すべてを安定順で移動

複数カテゴリから選んだタグは、カテゴリ表示順、カテゴリ内のタグ順で並べて移動します。

### カテゴリ移動

カテゴリ行右端の専用ハンドルを使います。

- 大分類：大分類間で並べ替え。配下カテゴリがなければ中分類行へドロップして中分類へ変更
- 中分類：同階層の並べ替え、別の大分類への移動。配下カテゴリがなければ専用ドロップ領域で大分類へ変更
- 小分類：同階層の並べ替え、別の中分類への移動

通常の親カテゴリ移動では、子孫カテゴリと所属タグも一緒に移動します。大・中分類のレベル変更は配下カテゴリがない場合だけ許可し、配下カテゴリがある場合は先に子分類を移動するよう表示します。循環や階層レベル違反は拒否されます。

### 名称の直接編集

- 大分類・中分類・小分類：日本語名または英語名をダブルクリックし、行内の2項目をまとめて編集
- タグ：タグ名または日本語訳をダブルクリックし、行内の2項目をまとめて編集
- チェックボタンまたは Enter で保存、×ボタンまたは Esc でキャンセル

### 削除

- 大分類・中分類・小分類：名称をダブルクリックし、行内の削除ボタンから影響件数を確認して削除
- タグ：タグ名または日本語訳をダブルクリックし、行内の削除ボタンから削除
- 複数タグ：チェックボックスで選択後、上部の「選択中N件を削除」からまとめて削除

削除は確認ボタンをもう一度押した時点で反映されます。分類を削除すると配下の分類とタグも一緒に削除されます。誤って削除した場合は、通知またはヘッダーの「元に戻す」を使用できます。

### Undo／Redo

- Ctrl＋Z：Undo
- Ctrl＋Y：Redo
- Ctrl＋Shift＋Z：Redo

最大100操作を保持します。

## 保存

Chrome・Edgeなど対応ブラウザでは、タグ設定ファイルをOSのファイル選択画面から開き、同じセッション中だけファイルハンドルを保持します。「上書き保存」は書き込み可能なハンドルがある場合だけ有効になり、確認後に現在のファイルを更新します。

開いているファイル名が既定の `tag_catalog.json` 以外で、直接書き込めるファイルハンドルがない場合は、「上書き保存」から現在のファイル名を初期値にしたOSの保存画面を開きます。保存先と同名ファイルを確認して選択すると上書きできます。

「別名で保存」ではOSの保存場所選択画面を開き、読み込み元の場所を初期位置として提案します。候補名は次の形式です。

```text
元ファイル名_YYYYMMDD_HHmmss.json
```

File System Access APIに対応していないブラウザでは、ファイル読込と別名保存を従来のファイル入力・ダウンロードへ切り替えます。この場合は元ファイルへ書き込めないため、「上書き保存」は無効になります。エラーがある場合は保存を禁止し、重複などの警告は内容を確認したうえで保存できます。

## 対応形式

- 同梱カタログ：`schema_version` と `major_categories` を持つJSON
- ユーザーカタログ：`schema: "prompt-workbench/tag-catalog"`、`version: 1`、`categories`、`tags` を持つJSON

JSON以外のYAML、CSV、JavaScript、コメント付きJSONには対応しません。詳しくは [docs/file-format.md](docs/file-format.md) を参照してください。

## ビルド

```powershell
npm run build
```

本番成果物は `dist/client` に生成されます。

## トラブルシューティング

- `npm が見つかりません`：Node.js 20以上をインストールし、新しいターミナルで再実行してください。
- JSONを読み込めない：拡張子、末尾カンマ、引用符、ルートスキーマを確認してください。
- 列にタグが出ない：左ツリーで中分類を選び、検索・重複・選択中フィルターを解除してください。
- ドロップできない：タグの最終移動先は小分類です。大・中分類を展開して小分類へドロップしてください。
- エクスポートできない：書き出し前の変更プレビューに表示された重大なエラーを修正してください。

## 制限事項

- ブラウザは元ファイルの絶対パスを取得しません。
- JSONのコメントと重複プロパティ名は標準JSONで表現できないため維持できません。
- 文字コードはUTF-8のみです。UTF-8 BOMの有無、LF／CRLF、インデント、末尾改行は維持します。
- 既存の未知プロパティは保持しますが、新規カテゴリ・タグには元データ由来の未知値はありません。

データの取り扱いについては [docs/data-safety.md](docs/data-safety.md) を参照してください。
